# Médias du site
- Vidéo de fond : URL Pexels externe configurée dans `index.html`; à remplacer par un fichier sous licence confirmée pour une production pérenne.
- Poster du hero : image Unsplash utilisée comme secours.
- Photos des voitures : URL par modèle dans `script.js`; elles illustrent les modèles et ne confirment pas les véhicules exacts de l'agence.
- Logo et favicon sont stockés localement dans `assets/`.
